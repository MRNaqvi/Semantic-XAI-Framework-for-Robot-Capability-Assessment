XAI: LIME Explanation

LIME explains the local NN prediction around the current X, Y, Z task using feature weights for X, Y, and Z.

XAI Confidence / Stability

Run LIME to estimate whether the strongest local feature is stable for this XYZ task.

Explanation Quality

Shows which explanation sources are available for the current task.

LIME Local Explanation

LIME builds a local surrogate around the current XYZ task point and estimates how X, Y, and Z influence the nearby NN prediction.

SHAP Comparison

SHAP attributes the current NN prediction across X, Y, and Z for the selected Cartesian task point.

Integrated Gradients

Integrated Gradients explains the NN prediction by accumulating gradients from a zero XYZ baseline to the current task point.

Permutation Importance

Permutation Importance perturbs one coordinate at a time and measures how much the NN output changes.
